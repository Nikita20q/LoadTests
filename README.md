# Тестирование
Возможно некоторое количество ошибок из-за того-что могут иногда пересекаться id спутников и группировок при создании.
Количество пользователей - 50
Время разгона - 30с
Общее время тестирования - 60с

В тестах нет запроса на put, по причине того, что он работает некорректно

## Пользовательский сценарий

Пользователь выполняет полный цикл CRUD-операций со спутниковой группировкой:
просмотр, создание, чтение, обновление и удаление группировок и спутников.

### Последовательность действий:
1. `GET /api/constellations` — просмотр списка группировок
2. `POST /api/constellations` — создание новой группировки
3. `GET /api/constellations/{id}` — проверка создания
4. `POST /api/satellites` — добавление спутника
5. `GET /api/satellites` — просмотр списка спутников
6. `DELETE /api/satellites/{id}` — удаление спутника
7. `DELETE /api/constellations/{id}` — удаление группировки

## Запуск сервера
- docker compose up --build -d

## Запуск тестов
- jmeter -n -t satellite_load_test.jmx -l results.jtl -e -o jmeter-report
